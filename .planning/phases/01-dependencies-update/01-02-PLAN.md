<task type="auto">
  <name>Task 1: Remove unused dependencies</name>
  <files>package.json, pnpm-lock.yaml</files>
  <action>
Remove the following unused packages from package.json:

1. **eslint-config-prettier** (devDependency) -- NOT referenced in eslint.config.js. The ESLint config only uses `withNuxt()` from @nuxt/eslint. This package is dead weight. Run:
   `pnpm remove eslint-config-prettier`

2. **vue-router** (dependency) -- Nuxt manages vue-router internally as a dependency of `nuxt` itself. Having it explicitly in package.json is redundant and can cause version conflicts. Nuxt 4.x bundles vue-router v4.x. Run:
   `pnpm remove vue-router`
   Then verify that `pnpm dev` still starts (Nuxt should resolve vue-router from its own deps).

3. **crypto-js** (dependency) -- Used in `server/utils/redsys.js`. This one IS used, keep it. Verify by reading the file to confirm the import.

4. After removals, run `pnpm install` to update the lockfile.

5. Scan for any other potentially unused packages by checking:
   - `pnpm why <package>` for any package that looks suspicious
   - Grep the codebase for import statements of each remaining dependency
   - If any other unused packages found, remove them too

Do NOT remove packages that are Nuxt modules (nuxt-gtag, nuxt-umami, @nuxt/eslint, @pinia/nuxt) -- they are loaded via nuxt.config.ts modules array, not via direct imports.
  </action>
  <verify>
    <automated>pnpm install --frozen-lockfile 2>&1 | tail -3 && node -e "const p=require('./package.json'); const deps=Object.keys({...p.dependencies,...p.devDependencies}); console.log('Total packages:', deps.length); console.log('Has vue-router:', deps.includes('vue-router')); console.log('Has eslint-config-prettier:', deps.includes('eslint-config-prettier'))"</automated>
  </verify>
  <done>vue-router and eslint-config-prettier removed from package.json. No other unused packages remain. Lockfile is consistent.</done>
</task>
