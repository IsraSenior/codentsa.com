This task must be done atomically -- config and moves together. Order of operations matters.

**Step 1: Create target directories**
```bash
mkdir -p app/components/layout app/components/ui app/components/features
```

**Step 2: Update nuxt.config.ts**
Add the `components` array to the existing config. Place it after `modules`:
```javascript
components: [
  {
    path: '~/components/layout',
    pathPrefix: false,
  },
  {
    path: '~/components/ui',
    pathPrefix: false,
  },
  {
    path: '~/components/features',
    pathPrefix: true,
  },
],
```
IMPORTANT: `layout/` and `ui/` use `pathPrefix: false` (flat files, unique names). `features/` uses `pathPrefix: true` (subdirectories provide domain prefix like ProductCard, CartItem). The `features/` directory is the scan root, so "features" itself is NOT included in component names.
